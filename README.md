# Үйлөнүү тойго чакыруу — Элдияр & Медина

13-ноябрь 2026-жыл, жума, саат 17:00 · «Жетиген» рестораны.
Той ээлери: Кубаныч & Шааркан.
Сайт-приглашение без сборки и зависимостей: чистые HTML / CSS / JS.

## Ссылки

Основная ссылка для гостей — вариант «Зумурут»:
**https://magamed56.github.io/eldiyar-medina/**

| Вариант | Адрес | Оформление |
|---------|-------|------------|
| «Зумурут» (основной) | `/` | изумруд и золото, ар-деко, кочкор мүйүз; обложка — конверт с восковой печатью «Э&М»; золотые веера и орнаменты по краям разделов |
| «Күз» | `/v2/` | осень: терракота, охра, олива, пампасная трава, бохо-арки; обложка — арка, через которую «входишь» в приглашение; падают листья |
| «Ак» | `/v3/` | молочно-белый, графит и тонкое золото, минимализм; обложка — открытка, раскрывается как книжка |

Все варианты читают один `config.js`, один `script.js` и одну музыку `assets/music.mp3`
(«Свадебная» — Мот). Чтобы сделать основным другой вариант, поменяйте местами его
`index.html` + `style.css` с корневыми и поправьте пути к `config.js` / `script.js` (`../` в подпапке).

Персональная ссылка: добавьте `?g=Имя` — например
`https://magamed56.github.io/eldiyar-medina/?g=Асан%20жана%20Айгүл`:
на обложке и главном экране появится «Урматтуу Асан жана Айгүл!», имя подставится в анкету.

## Как поменять данные

Всё — в **`config.js`**: имена, `hosts` (той ээлери, одна или несколько семей), дата и время,
ресторан (`venueName`, `routeUrl` — ссылка 2GIS, `coords` — для карты), тексты и заметки
(`notes`, иконки `clock | flower | camera | heart | gift | music | dress`), русские тексты в `ru`.

Если меняются имена или дата — пересоздайте `assets/og.jpg` (скриншот `og.html` 1080×1080)
и `assets/toy.ics` (календарь для iPhone).

## Куда приходят ответы гостей

Для этой пары ответы идут **только в Google Таблицу** (Telegram выключен: `telegram` в `config.js` пустой).

1. **Google Таблица** (ответы + пожелания на сайте) — создайте таблицу → Расширения → Apps Script →
   вставьте `google-apps-script.js` → сохраните → выполните `setupSheet` (разрешите доступ:
   «Дополнительно» → «Перейти к проекту») → Развернуть → Новое развёртывание → Веб-приложение,
   «Выполнять от имени: Я», «Доступ: Все» → URL (…/exec) вставьте в `googleScriptUrl`.
   В листе «Жооптор»: время, имя, ответ, число гостей, пожелание и галочка «Сайтта»;
   справа итоги (сколько придёт, сколько нет, всего человек; пересчитываются и при ручном удалении строк).
   Проверка версии: `…/exec?action=version`. Если гость меняет ответ,
   обновляется его строка. Пожелания с галочкой «Сайтта» показываются на сайте в разделе
   «Каалоолор» — снимите галочку, чтобы скрыть пожелание.
   Там же, под итогами, — «Сайтты көрдү»: сколько человек открыли приглашение (и ответившие, и нет;
   один телефон считается один раз). Это же число мелко показано в самом конце сайта.
2. **WhatsApp** (запасной, по желанию) — `whatsapp: "996…"`: гость сам отправляет готовое сообщение.
3. **Telegram** (если когда-нибудь понадобится) — `telegram: { token, chatId }`: бот-администратор в канале/группе пары,
   id группы — из `https://api.telegram.org/bot<TOKEN>/getUpdates`.

## Публикация

GitHub Pages раздаёт ветку `gh-pages`. Workflow `.github/workflows/deploy.yml` при каждом пуше
в `main` копирует её в `gh-pages` (и проставляет версию файлов, чтобы телефоны не показывали старое).
Один раз включите: Settings → Pages → Build and deployment → Deploy from a branch → `gh-pages` / `(root)`.

Локально: `python3 -m http.server 8080` → http://localhost:8080
